Privacy policy

Effective 18 November 2026.

Purpose and data access

The QuantumScope OAuth client is intended for the operator's personal rclone storage workflow. Google Drive authorization allows rclone to list, read, upload, download, verify, modify and delete Drive files when the operator requests these operations. Access may extend to all files in the authorized Drive account.

Use, storage and sharing

Google Drive data is used to manage and archive the operator's research files. Files are stored on the operator's computers and in the operator's own Google Drive. OAuth credentials are stored in the local rclone configuration. The workflow is not intended to sell Google user data, use it for advertising, transfer it to unrelated third parties, or train generalized AI models using it. The operator controls file retention and deletion. Access is restricted to the authorized operator and the software needed for the requested file operations.

Authorization and deletion

The operator can revoke Google Drive access at Google Account connections, remove the local rclone remote, and delete files using Google Drive or local tools. This informational website does not collect Google OAuth tokens or access Google Drive data. GitHub Pages hosts the website and may process ordinary website request information under GitHub's privacy statement.

Questions about this workflow may be directed to the operator through the project owner's GitHub profile. Information about Google's handling of data is available in Google's privacy policy.
